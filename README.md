# GHCS Classic Worldgen

Самостоятельный мод GHCS для **Minecraft 1.21.1 / NeoForge 21.1.249+ / Java 21**. Проверен на NeoForge 21.1.265. Версия **0.1.0**, предварительная: релизная 1.0 будет после полного игрового тестирования автора сборки.

Классические пещеры и руды, дно Y=0 и верх Y=320 — как отдельный выбираемый пресет. Обычный мир сохраняет ванильные параметры.

## Зависимости

Обязательны только Minecraft и NeoForge. Другие GHCS-модули, Create, Aeronautics, Farmer’s Delight и моды рюкзаков не требуются. Отсутствующий сторонний рецепт не создаётся и не заменяется. Совместимые интеграции включаются только при наличии соответствующего содержимого. Обязательные платформенные зависимости объявлены в `META-INF/neoforge.mods.toml` с пояснениями для стандартного экрана ошибок NeoForge. Необязательные интеграции и ошибки чтения конфигов выводятся предупреждениями при загрузке.

## Конфиги

При первом запуске создаётся `minecraft/config/ghcs-classic-worldgen/`. Файлы: **worldgen.json, templates.json**.

Менять исходные JSON рядом с `generated/`; папка `generated/` — перестраиваемый кеш датапака. Существующие пользовательские конфиги не перезаписываются при обновлении JAR. После изменения настроек полностью перезапустить игру или сервер. `/reload` перечитывает данные, но настройки JSON модуля фиксируются на время запуска. Некорректный синтаксис JSON вызывает предупреждение и применение заводских настроек на один запуск; ошибочный файл сохраняется.

## Сборка

```powershell
$env:JAVA_HOME = 'путь к JDK 21'
.\gradlew.bat build
```

JAR: `build/libs/ghcs-classic-worldgen-0.1.0.jar`. Готовый мод устанавливается на клиент и сервер. Исходные заводские конфиги находятся в `src/main/resources/defaults/`. Коммиты — Conventional Commits.

Другие модули и общие проверки: [интеграционный репозиторий GHCS](https://github.com/Roforus/Green-hill-Clean-steam-GHCS-pack-Minecraft-mod).

## Выбор генерации

При создании мира открыть вкладку «Мир» и выбрать тип **«Старое доброе — классический мир»**. ID пресета: `ghcs_classic:classic`; для выделенного сервера — `level-type=ghcs_classic:classic` до первого создания мира. Пресет добавлен в обычный список типов, а не заменяет «Обычный».

Руды и карверы подменяются только у генератора с настройками `ghcs_classic:*`. Ванильные `minecraft:overworld`, распределение руд обычного мира и остальные измерения не переписываются. Обычные биомы и структуры сохраняются; их отбор выполняет отдельный Unwanted Content, если он установлен.

Пресет возвращает старые диапазоны и частоты, но использует рельеф и алгоритмы Minecraft 1.21.1, поэтому сид не воспроизводит поблочно мир 1.12.2. Старые экспериментальные миры монолитного GHCS с принудительно изменённым `minecraft:overworld` автоматически не конвертируются: рекомендуется новый мир. Мод не переписывает сохранения.
